# Irfan Shaikh — Portfolio

Premium brutalist-editorial personal portfolio (Vite + React + GSAP).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Stack

- React 19 + TypeScript
- GSAP ScrollTrigger
- Character pose images under `src/assets/images/character/`
